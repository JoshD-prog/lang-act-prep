# KC Cram Course brand assets

`logo-master.png` is the canonical logo artwork for this website. It has a transparent background and tightly cropped padding.

All other active logo files must be derived from that master without redrawing or restyling it:

- `logo.png`: 1024 × 1024 transparent organization/structured-data logo
- `logo-nav.png`: 256 × 256 transparent navbar, favicon, and touch icon
- `logo-social.jpg`: 1200 × 630 social-sharing image on a neutral background

Do not edit a derivative directly. Update the master first, then regenerate every derivative from it.

The older JPG files are retained only as historical source material and are not referenced by the application.
